# There is nothing here to hide from a crawler, and nothing here that exists
# only to pass a link. If that ever stops being true, the right fix is to
# delete the page, not to hide it in this file.
#
# A robots.txt is only read at the root of a host. This site is a project
# page served from https://maaaaaaxx.github.io/website/, so the file a crawler
# actually fetches is https://maaaaaaxx.github.io/robots.txt, which belongs to
# the account's user site and not to this repository. This copy is served at
# /Website/robots.txt, where nothing is obliged to look for it.
#
# It is kept anyway for two reasons: it states the intent alongside the pages
# it describes, and it is already correct on the day a user site or a custom
# domain exists to serve it from the root. The line that does the work in the
# meantime is the Sitemap: below, which is submitted to Search Console and to
# Bing Webmaster Tools by hand.
